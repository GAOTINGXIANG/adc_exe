# adc_exe — 氨气检测 ESP32 双模式上位机

基于 PyQt5 + pyqtgraph 开发的 ESP32 氨气传感器数据采集与控制系统，支持串口和 TCP/WiFi 双模式通信，提供实时波形显示、阻值计算、设备控制等功能。

## 功能概览

### 1. 双模式通信
- **串口模式**：通过 COM 口直连 ESP32，波特率 115200
- **网络模式**：通过 TCP/WiFi 连接 ESP32 服务器

### 2. 实时数据采集与显示
- 4 路传感器（T1 / T2 / M1 / M2）ADC 值实时波形显示，范围 0~4095
- ADC 视图与阻值视图一键切换
- 支持图表网格背景、自动滚动、X/Y 轴自动匹配
- 鼠标交互：左键拖拽平移、右键拖拽缩放、滚轮缩放、右键菜单（View All / Invert Axis 等）

### 3. 温湿度与阻值计算
- 实时解析 TEM / HUM 数据并显示温湿度
- 根据 ADC 值与采样电阻自动计算传感器阻值，支持自动单位换算（Ω / KΩ / MΩ / GΩ）

### 4. 设备控制
- **采样通道**：每路传感器独立选择 0~6 通道（对应 10K / 100K / 1M / 10M / 100M / 1G / 10G 采样电阻）
- **温度百分比**：每路传感器独立控制 0~100%，向设备发送 `PERCENTx:y` 指令
- **加热台**：开关控制，发送 `HEATER:0/1` 指令
- **风扇**：开关控制，发送 `FAN:0/1` 指令
- **采样频率**：可调 1~1000 Hz，按设定频率刷新曲线和日志

### 5. 采样通道自动匹配
- 四路并行自动匹配，从通道 6 向通道 0 依次切换
- 可配置 ADC 值范围（上限/下限）和切换延迟
- 匹配完成后自动更新通道选择器

### 6. 数据管理
- 导出 CSV：包含时间、四路 ADC 值、温湿度数据
- 日志系统：可配置日志缓存条数、自动滚动、暂停/恢复
- 图表独立暂停/恢复

### 7. 断线检测
- 串口设备丢失自动检测并提示

## 通信协议

### 设备 → 上位机（数据上报）
```
ADC1:1234     # T1 传感器 ADC 值（0~4095）
ADC2:1234     # T2 传感器 ADC 值（0~4095）
ADC3:1234     # M1 传感器 ADC 值（0~4095）
ADC4:1234     # M2 传感器 ADC 值（0~4095）
TEM:25.5      # 温度（℃）
HUM:60.2      # 湿度（%RH）
```

### 上位机 → 设备（控制指令）
```
CHANNELx:y    # 设置通道，x=1~4（对应 T1/T2/M1/M2），y=0~6（采样电阻档位）
PERCENTx:y    # 温度百分比，x=1~4，y=0~100
HEATER:0      # 加热台关
HEATER:1      # 加热台开
FAN:0         # 风扇关
FAN:1         # 风扇开
```

## 软件架构

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│ SerialWorker │────▶│   Signals    │────▶│ MainWindow  │
│  (串口通信)   │     │ (信号/事件)   │     │  (UI/控制)   │
└─────────────┘     └──────────────┘     └─────────────┘
       │                  ▲                     │
       │            ┌─────┴─────┐               │
       └───────────▶│ DataState │◀──────────────┘
                    │ (数据存储) │
       ┌───────────▶│            │◀──────────────┐
       │            └───────────┘               │
┌─────────────┐                          ┌─────────────┐
│  TcpWorker  │                          │ DataParser  │
│  (TCP通信)   │                          │ (数据解析)   │
└─────────────┘                          └─────────────┘
```

- **MainWindow**：主界面，负责 UI 渲染、用户交互、定时器管理
- **SerialWorker / TcpWorker**：工作线程，独立处理串口/TCP 数据收发，避免阻塞 UI
- **Signals**：Qt 信号机制，实现线程间解耦通信
- **DataState**：线程安全的数据中心，维护最新 ADC 值、温湿度、导出缓存
- **DataParser**：解析设备数据帧，提取 ADC 值和温湿度

- Python 3.8+

```bash
pip install pyqt5 pyqtgraph pyserial
```

```bash
python main.py
```

## 使用说明

### 连接设备

1. **串口模式**：选择"串口接收" → 刷新串口列表 → 选择 COM 口 → 点击"连接"
2. **网络模式**：选择"网络接收" → 输入 ESP32 服务器 IP 和端口 → 点击"连接"

### 图表操作

| 操作 | 功能 |
|---|---|
| 采样点数 | 设置 X 轴数据总量，调整时保留已有数据连续性 |
| 曲线选择 T1/T2/M1/M2 | 切换对应曲线的显示/隐藏 |
| 视图切换 | ADC 视图 ⇄ 阻值视图 |
| 自动滚动 | 曲线随新数据自动向右滚动 |
| 自动匹配 | 自动调整 X/Y 轴范围适配当前数据 |
| 网格 | 切换图表背景网格 |
| 图表 ▶/⏸ | 暂停/恢复图表刷新 |
| 清除图表 | 清空所有历史数据 |

### 设备控制

| 控制项 | 说明 |
|---|---|
| 频率(HZ/S) | 设置上位机采样刷新频率，默认 1Hz |
| 采样通道 | 每路传感器选择 0~6 通道（10K~10G 采样电阻） |
| 自动匹配 | 四路并行自动匹配最佳采样通道 |
| 温度百分比 | 每路独立 0~100%，点击"发送"生效 |
| 加热台 开/关 | 控制加热台开关 |
| 风扇 开/关 | 控制风扇开关 |

### 数据导出

点击"导出CSV数据"按钮，选择保存路径，导出的 CSV 包含：时间、T1、T2、M1、M2、温度(℃)、湿度(%RH)。
